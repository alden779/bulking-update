GAIN 50 PWA v3.2 - More Foods

Perubahan:
- Lebih dari 50 pilihan makanan.
- Tetap tanpa ikan.
- Kategori: Karbo, Lauk, Sayur/Warteg, Snack, Buah, Minuman.
- Mode Manual punya pencarian makanan dan filter kategori.
- Meal plan otomatis berputar selama 14 hari supaya lebih bervariasi.
- Porsi dan kalori menggunakan acuan TKPI/BPOM/AFCT/PPKP yang tertulis di aplikasi.
- Dancow FortiGro Coklat: 160 kkal per sajian sekitar 38-39 g.
- Fitur PWA, offline, LocalStorage, workout Morning/Evening, progress, history, export/import tetap ada.

Upload semua file di folder ini ke root GitHub Pages:
index.html
manifest.webmanifest
service-worker.js
icon-192.png
icon-512.png

Catatan:
Masakan warteg dapat berbeda karena minyak, resep, ukuran potongan, dan berat aktual.
Angka di aplikasi memakai porsi referensi yang tertulis pada tiap item.
